Seed-фразы для реальных криптокошельков генерируйте только офлайн, на проверенном устройстве.

[ LOCAL FIRST · ZERO DEPENDENCIES ]

EntropyLab — набор из трёх генераторов, работающих полностью локально в вашем браузере.

Вся случайность берётся из Web Crypto API (crypto.getRandomValues), а не из Math.random(). Ничего не отправляется на сервер — можно даже отключить интернет и продолжить пользоваться страницей.

[ GENERATOR ]

Пароли

Настраиваемая длина, наборы символов, гарантия хотя бы одного символа из каждой выбранной категории, шкала энтропии.

[ GENERATOR ]

Логины

Случайные имена пользователей: читаемые (слово+слово+число) или полностью случайные строки.

[ GENERATOR ]

Seed-фразы

Мнемонические фразы по стандарту BIP-39 (официальный английский словарь, 12–24 слова) с корректной контрольной суммой SHA-256.

Это открытый инструмент, а не аппаратный кошелёк. Для хранения реальных крипто-средств используйте офлайн-генерацию и проверенное защищённое устройство — подробности на вкладке «Seed-фразы».
