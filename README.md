## ✦ Структура сайта

Страница построена вокруг общей верхней панели навигации и четырёх вкладок. На широких и узких экранах интерфейс растягивается по доступной ширине окна, сохраняя внутренние отступы для удобного чтения и управления.

```text
│   ├── Название EntropyLab
│   ├── Навигация по вкладкам
│   └── Переключатели языка и темы
├── О наборе
│   ├── Краткое описание локальной работы
│   ├── Обзор трёх генераторов
│   ├── Информация о случайности и конфиденциальности
│   └── Разделитель и ссылка «by m0lfiln»
├── Пароли
│   ├── Поле результата и копирование
│   ├── Индикатор надёжности
│   ├── Длина и наборы символов
│   ├── Кнопка генерации
│   └── Разделитель и ссылка «by m0lfiln»
├── Логины
│   ├── Поле результата и копирование
│   ├── Выбор читаемого или случайного формата

    ├── Предупреждение о безопасном использовании

    ├── Кнопка генерации
    └── Разделитель и ссылка «by m0lfiln»
```

### Общие элементы

- **Навигация:** переключает между вкладками «О наборе», «Пароли», «Логины» и «Seed-фразы».
- **Язык:** интерфейс доступен на русском и английском языках.
- **Тема:** можно выбрать тёмное или светлое оформление.
- **Завершение вкладки:** каждая вкладка заканчивается одинаковой акцентной линией и ссылкой автора.
- **Адаптивность:** расположение элементов приспосабливается к ширине экрана.

## ✦ Возможности

- **Генератор паролей:** длина 8–64 символа; заглавные и строчные буквы, цифры и символы; гарантия хотя бы одного символа из каждой выбранной категории; индикатор надёжности.
- **Генератор логинов:** читаемые сочетания слов с необязательными цифрами или случайная строка длиной 5–24 символа.
- **Генератор seed-фраз:** английский словарь BIP-39 из 2048 слов; варианты на 12, 15, 18, 21 или 24 слова; контрольная сумма SHA-256.
- **Копирование:** результат каждого генератора можно скопировать в один клик.
- **Работа без сборки:** сайт реализован на HTML, CSS и чистом JavaScript, без пакетных зависимостей.

## ✦ Безопасность

- Случайные значения создаются в браузере с помощью `crypto.getRandomValues()` из Web Crypto API, а не `Math.random()`.
- Сгенерированные данные не отправляются на сервер и не сохраняются сайтом.
- Сайт может загружать веб-шрифты из Google Fonts; этот запрос не содержит сгенерированные пароли, логины или seed-фразы.

> [!WARNING]
> **Не используйте seed-фразу, созданную на любом сайте, включая этот, для кошелька с реальными средствами.** Для настоящих сбережений используйте аппаратный кошелёк или офлайн-генерацию на проверенном устройстве. Генератор seed-фраз предназначен для обучения, тестовых кошельков и разработки.

Проект предоставляется «как есть». Пользователь самостоятельно отвечает за хранение и использование созданных данных.

## ✦ Запуск

**Онлайн:** [m0lfiln.github.io/EntropyLab](https://m0lfiln.github.io/EntropyLab/)

**Локально** — сборка и установка зависимостей не требуются:

```bash
git clone https://github.com/m0lfiln/EntropyLab.git
cd EntropyLab
python -m http.server 8000
```

Затем откройте <http://localhost:8000/>. Также можно открыть `index.html` напрямую в браузере, однако некоторые браузерные функции могут требовать локальный HTTP-сервер.
